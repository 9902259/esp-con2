ESP-CON2 / LOCAL USB CONTROL

ESP32-S3 board controller

Joy-Con 2 L+R or Pro Controller 2. One USB connection, direct from your browser.

CONNECTIONDisconnected

Connect your ESP32-S3 board with a USB data cable.

Close the MCP server, CLI, and serial monitors before connecting. Only one can own the USB port.

Buttons

Each click is a bounded press, followed by release.

In Joy-Con mode, SL and SR reach both halves together. HOME, Capture, and C can open system UI.

Control sticks

Set a position, then send it for the selected duration.

Axis direction and calibration need console-side verification.

Controller mode

Unified firmware required. Switching reboots; reconnect afterward. Bonds are preserved.

Pairing

Open Controllers → Change Grip/Order on Switch 2. Wait for readiness, then select with L+R.
